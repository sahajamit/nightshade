Nightshade

Sites

One rule per site. The most specific pattern wins: a path beats a host, a host beats its parent domain. Sites without a rule use the global default.

SiteModeBoostsFixesNote

Global default

Applies to every site without its own rule, and fills in anything a rule leaves out.

100 = images untouched.

Palettes

Used by Bespoke mode. Background and text drive the recolouring; every colour is available to custom CSS as var(--ns-bg), var(--ns-text) and so on.

Config file

The whole configuration as JSON. This is the same document the nightshade CLI edits in ~/.nightshade/config.json. Edit, validate and save here, or import a file.

Agent bridge

Lets an AI agent (or you, from a terminal) change Nightshade through a config file and a CLI. Changes show up in open tabs within a second.

npm link                       # in a clone; puts nightshade on your PATH
nightshade bridge install      # registers the bridge with Chrome
nightshade set linkedin.com --mode native --contrast-floor 4.5
nightshade fix add mail.google.com '[role=checkbox]' strengthen-border
